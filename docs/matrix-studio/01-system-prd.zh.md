# DSH Matrix Studio: 开放式 AI 原生技术栈拼装矩阵 (PRD)

> **文档版本**: v1.3.0 (全功能集成与沉浸式 UI 工作台版)
> **核心定位**: **“全开放、零绑定的可组合软件工程底座”** —— 以 Cordis 微内核为基石，建立标准化的技术栈插件市场与乐高式组装中枢。集成了**从 0 到 1 自由拼装**、**行业模板开箱即用**、**老项目逆向复刻翻新**以及**四区联动可视化沉浸式工作台**。


## 3. 核心功能系统

### 3.1 技术栈拼装器中枢 (`ctx.matrixComposer`)
- 管理各维度的可用积木 Manifest，提供可视化选择器与 CLI 向导；
- 解析 `stack.recipe.yml`，动态向 Agent 注入对应技术栈的语法规则、最佳实践与工具限制。

### 3.2 统一数据契约中枢 (`ctx.matrixContract`)
- 单一数据源（Drizzle Schema + TypeBox / Zod）；
- 自动生成前后端零胶水代码的强类型 RPC（如 Hono RPC / tRPC），保障跨端字段一致性。

### 3.3 存量老项目逆向复刻引擎 (`ctx.matrixIngest.project`)
- **零运行静态分析**：使用 Ripgrep 极速扫描用户本地老旧项目（如 Vue2/Webpack/ElementUI）；
- **拓扑还原**：提取路由拓扑、Vue 组件层级与 API 请求；
- **现代重构**：一键平滑转译为现代技术栈（UniApp Vue3 + lucky-ui + Hono RPC）。

### 3.4 轻量配方与模板中心 (`ctx.matrixComposer.templates`)
- **超轻量纯元数据**：模板由 `template.recipe.yml` + 业务蓝图 Markdown + 种子 Git 组成，零运行时占用；
- **开箱即改**：一键载入电商商城、SaaS 门户等模板，且所有技术栈组件仍可随意自由替换。

### 3.5 多模态设计接入 (`ctx.matrixIngest.design`)
- 将 Figma JSON、UI 截图、PRD 自然语言转化为框架无关的中立 **Intermediate Layout AST (IL-AST)**。

### 3.6 四区联动沉浸式 UI 工作台 (`ctx.matrixUiStudio`)
- **彻底告别纯文本聊天窗口**，提供包含“智能副驾决策流”、“多端联动实时沙箱画布（手机模拟器+PC官网+Admin）”、“双向属性微调与 Monaco 源码面板”在内的专业级 Studio 界面。

### 3.7 自动化构建与多端发布 (`ctx.matrixDelivery`)
- 小程序 CI（微信/支付宝）、容器化 Docker、Serverless Edge 一键分发。
