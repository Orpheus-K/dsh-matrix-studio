## 2. 四大核心交互工作区设计

### 2.1 左区：AI 智能副驾与结构化卡片流 (AI Copilot & Workflow)
- **非纯文本渲染**：对话流中嵌入富交互卡片（Rich Action Cards）：
  1. **交互式决策卡片（Decision Card）**：当配置存在多种方案时，渲染可视化单选/多选胶囊，用户一键点击即完成决策（而非手打文字）；
  2. **任务进度清单（Live Todo Checklist）**：实时展示当前跨端任务的执行状态、文件改动计数与耗时；
  3. **代码差异折叠预览（Diff Drawer）**：直观展示 Agent 对 Vue/TS 文件的具体修改行。

---

### 2.2 中区：多端混合视口沙箱画布 (Multi-Viewport Live Canvas)
提供真正的“所见即所得”多端联动预览，彻底告别盲调代码：
- **📱 移动端模拟器（Mobile Frame）**：
  - 真实渲染 UniApp (Vue3 + `lucky-ui`) 的 H5/小程序页面；
  - 顶部配备设备切换栏：iPhone / Android / iPad、深色模式切换、扫码真机预览。
- **💻 PC 响应式视口（Desktop View）**：
  - 实时渲染 Nuxt 4 SSR 门户或 PC Web 应用，支持拖拽调整视口宽度验证响应式布局。
- **📊 管理中台视口（Admin View）**：
  - 实时预览 Vben Admin v5 的数据表格、搜索表单与权限控制。
- **🗄️ 数据契约看板（Data Contract View）**：
  - 自动渲染 Drizzle 数据库 ER 图与 Swagger/OpenAPI 在线调试器。
- **🎯 画布反向点选（Visual Element Inspector）**：
  - 在模拟器中点击任意组件（如一个 `<lk-button>`），右侧面板立刻定位该组件的代码行与属性面板！

---

### 2.3 右区：可视化属性微调与源码双向引擎 (Dual-Engine Property & Code)
- **🎨 视觉属性微调面板（No-Code Property Sheet）**：
  - 无需手写代码，直接可视化调整组件 Props（颜色、尺寸、圆角、文字、对齐方式、间距）；
  - **双向 AST 同步**：用户在面板拖动滑块或修改颜色，后台自动精准修改 Vue SFC 文件中的代码，并触发 30ms 毫秒级 HMR 实时热更新！
- **📝 专业 Monaco 代码编辑器**：
  - 支持直接在浏览器内手写 Vue3、TypeScript 与 Tailwind 类名，配备完整的智能补全与语法高亮。

---

### 2.4 顶部与模态：三大沉浸式交互中心

#### ① 🧩 技术栈乐高拼装面板 (Stack Composer Modal)
像挑选积木一样可视化组装技术栈：
- 采用卡片矩阵（Card Matrix）设计，每个技术栈选项附带图标、特性标签与性能跑分；
- 勾选时动态计算兼容性并提示最佳搭配（例如：选择 UniApp 时，高亮推荐 `lucky-ui` 与 `Tailwind v4`）。

#### ② 🎨 行业模板市场画廊 (Template Gallery Drawer)
- 抽屉式模板画廊，展示电商零售、SaaS 门户、企业 CRM、AI 对话工具等开箱即用模板；
- 包含卡片式实时缩略图、技术栈构成标签、一键“应用模板”按钮。

#### ③ 🔄 老项目智能复刻工作台 (Project Replicator Zone)
- **拖拽区域（Drop-Zone）**：用户直接将本地老旧项目文件夹拖入该区域；
- **秒级体检雷达**：可视化展示检测到的老技术栈（如：Vue 2.6、Webpack 4、Axios、Element UI）；
- **迁移重构对照表**：一键展示迁移前后的架构对比预览（Vue2 -> Vue3, Element -> lucky-ui/Vben5, Axios -> Hono RPC），点击“开始重构”即由 Agent 自动化翻新！

## 3. 技术实现机制 (前端扩展实现)

该界面完全基于 `deepseek-harness` 的前端扩展协议实现：
1. **组件注册**：在 `packages/matrix/ui-studio` 中注册自定义的 React View 与 Inspector Panel；
2. **WebSocket 通信**：通过 DSH 原生的会话通道同步文件变更、终端日志与 HMR 信号；
3. **WebContainer 沙箱挂载**：在 iframe 内加载打包产物与微型 Node.js 运行时，保证本地资源零消耗。
